# TFI - Palabras Encadenadas

## Como instalar y levantar el proyecto
Antes que nada, es necesario tener instalado Node.js el cual incluye npm que es necesario para instalar y levantar el proyecto:
1. Correr el comando "npm install" para instalar las dependencias.
2. Correr el comando "npm run dev" para levantar el proyecto.
3. Abrir con un navgador la url local indicada que es "http://localhost:5173/".

Y listo, jugar.

### Extras a los que llegue
